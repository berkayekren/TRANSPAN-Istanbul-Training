# TRANSPAN Istanbul Training - Multiomics Data Integration

## COST Action CA21116

This repository is part of the **COST Action CA21116 - TRANSPAN** (TRANSfer of Parasites Across biogeographical Networks).

COST Actions are networking instruments that enable researchers and innovators to collaborate across Europe and beyond. TRANSPAN brings together experts to study parasite transfer patterns and their implications through advanced computational and data integration approaches.

## About This Repository

This repository contains training materials from the TRANSPAN training session held in Istanbul on **September 23-25, 2024**.

## Contents

- **omics_integration.pdf** - Comprehensive presentation on multiomics data integration tools delivered on the final day of the training session. This 25-page presentation covers:
  - Introduction to multiomics data integration approaches
  - Tools and methodologies for integrating different omics layers
  - Practical applications in biological research
  - Best practices and computational workflows

## Training Information

- **Location**: Istanbul, Turkey
